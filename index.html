Olympus

Olympus is a personal-assistant workflow that can work with an authorized Gmail account to help with personal-assistant use.

The current integration uses Gmail's read-only permission, gmail.readonly. In plain language, it can read Gmail profile information and retrieve messages: it can list messages and get message content, including the body. It does not send, edit, or delete Gmail messages, and the current runner does not activate a schedule.

Email content used by the workflow is stored locally in SQLite for personal-assistant use. Details that require a policy decision or broader implementation review are identified in the trace below rather than presented as promises.
