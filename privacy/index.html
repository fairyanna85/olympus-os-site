Privacy Policy

What the current integration accesses

The current Gmail integration requests only the gmail.readonly scope. It uses Gmail profile, message-list, and message-get operations. This is read-only access: the current integration does not send, edit, or delete Gmail messages.

What is stored

The workflow stores email content, including message bodies, in a local SQLite database for personal-assistant use. The current runner does not activate a schedule.

This page does not make claims about retention duration, deletion procedures, storage protection, sharing or processing destinations, backups, telemetry, account isolation, or availability. Those facts remain open and are marked F2, F3, F4, and F8 in the trace below. The intended user population and final policy review remain open under F5 and F6.

Privacy/contact route: lp.olympus.assistant@gmail.com
