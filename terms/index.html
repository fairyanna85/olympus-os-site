Current behavior

Olympus currently describes a personal-assistant workflow using an authorized Gmail account. The integration requests only gmail.readonly and uses Gmail profile, message-list, and message-get operations. It reads Gmail content, including message bodies, and stores that content locally in SQLite for personal-assistant use. The current runner does not activate a schedule.

These terms describe verified current behavior only. They do not state a retention period, deletion process, sharing or sale policy, security standard, availability commitment, legal entity, warranty, or user population.
